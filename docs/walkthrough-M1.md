# Walkthrough: Passk
Data flow: `logs.read_logs` -> `TrialTable` (one row per trial) -> `counts(model)` per task -> `stats` -> `compare`/`report`. Design decisions: zero runtime dependencies for the core (extras add zstd/Inspect/OTel); the task is the unit of analysis; every statistical choice is checked by simulation, and one was changed because of it. What breaks: partial-credit scorers, logs from pre-0.3 Inspect schemas (unknown fields are surfaced, not guessed), pooled logs of the same model name (trials are pooled per model; pass separate directories to keep runs apart).
